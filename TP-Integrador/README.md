Frontend
- herramienta: Streamlit

- Interfaz
    - Sin autenticacion
    - Que tenga un titulo y descripcion claro, pero conciso, de lo que hace.
    - Campos requeridos:
        - Un boton para subir una imagen o conjunto de imagenes.
        - Una nota que indique que se puede subir hasta 10 archivos a la vez.
        - Una ventana con los archivos seleccionados.
    - Una vez transformado todos los archivos, que muestre un boton para descargarlos, con todos sus nombres originales
